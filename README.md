# 방치형 보스 RPG 모드 도감

모바일과 데스크톱 브라우저에서 열 수 있는 단일 HTML 모드 도감입니다.

## 실행하기
- `index.html` 파일을 브라우저에서 열면 됩니다.
- 별도의 빌드 과정이나 외부 라이브러리 설치가 필요하지 않습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 `index.html`과 `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고, 브랜치는 `main`, 폴더는 `/ (root)`로 지정한 뒤 저장합니다.
5. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

## 파일 구성
- `index.html` — 웹페이지 전체 코드 및 내장 리소스
- `README.md` — 프로젝트 설명과 배포 방법
